# 年会在线大屏抽奖系统

一个功能完整、视觉吸引力强的年会在线大屏抽奖网页应用，支持多种抽奖模式、参与者管理、奖项设置和历史记录查询等功能。

## 功能特性

### 核心功能模块
- **参与者信息管理系统**：支持批量导入、手动添加及数据验证
- **多种抽奖模式**：包括随机抽取、滚动抽奖、指定奖项抽取等
- **奖项设置与管理**：支持自定义奖项名称、数量及展示效果
- **抽奖结果实时展示**：实时显示中奖结果，并提供历史记录查询功能
- **管理员控制面板**：含抽奖控制、数据重置、系统设置等权限

### 技术实现
- **响应式设计**：确保在不同尺寸的大屏显示器上均有良好表现
- **现代前端框架**：使用Vue 3 + Vite构建单页应用
- **流畅的动画效果**：特别是抽奖过程中的滚动动画
- **模块化开发**：确保代码可维护性和可扩展性
- **本地数据存储**：防止页面刷新导致数据丢失

### 部署支持
- **Netlify部署标准**：项目结构符合Netlify部署标准
- **一键部署**：支持通过Netlify的一键部署功能完成部署流程
- **优化资源加载**：确保首次加载时间不超过3秒
- **自动构建与测试**：实现部署后的自动构建与测试验证

### 视觉与交互
- **多套主题模板**：提供至少3套不同风格的主题模板供选择
- **自定义设置**：支持自定义背景图片、颜色方案及字体样式
- **动态视觉效果**：实现抽奖过程中的动态视觉效果和声效反馈
- **简洁大方的界面**：重点突出抽奖信息和结果展示

### 安全与性能
- **防作弊机制**：实现基本的防作弊机制
- **高并发稳定性**：确保在高并发场景下的稳定性
- **代码规范**：代码需通过ESLint等工具的规范检查
- **性能优化**：页面性能指标需达到Lighthouse评分85分以上

## 快速开始

### 环境要求
- Node.js 18.0.0 或更高版本
- npm 9.0.0 或更高版本

### 安装与运行

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd lottery-app
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **构建生产版本**
   ```bash
   npm run build
   ```

5. **预览生产构建**
   ```bash
   npm run preview
   ```

## 使用指南

### 1. 参与者管理
- **手动添加**：点击"手动添加"按钮，填写姓名和编号
- **批量导入**：点击"批量导入"按钮，上传CSV或TXT文件
  - 文件格式：姓名,编号（每行一条记录）
  - 示例：张三,001
- **搜索参与者**：使用搜索框快速查找参与者
- **删除参与者**：点击参与者列表中的"删除"按钮

### 2. 奖项设置
- **添加奖项**：点击"添加奖项"按钮，填写奖项名称、获奖人数和展示颜色
- **编辑奖项**：点击奖项卡片中的"编辑"按钮，修改奖项信息
- **删除奖项**：点击奖项卡片中的"删除"按钮

### 3. 抽奖流程
1. **选择抽奖模式**：随机抽取、滚动抽奖或指定奖项
2. **选择奖项**（仅指定奖项模式）：从下拉菜单中选择奖项
3. **开始抽奖**：点击"开始抽奖"按钮
4. **停止抽奖**：点击"停止抽奖"按钮，显示中奖结果
5. **查看结果**：抽奖结果会实时显示，并自动添加到历史记录

### 4. 历史记录
- **查看历史**：浏览所有抽奖记录
- **搜索记录**：使用搜索框查找特定记录
- **按奖项筛选**：从下拉菜单中选择奖项进行筛选
- **导出记录**：点击"导出记录"按钮，下载CSV格式的抽奖记录
- **清空历史**：点击"清空历史"按钮，清空所有抽奖记录

## 部署到Netlify

### 一键部署
1. 登录Netlify账号
2. 点击"New site from Git"
3. 选择你的Git仓库
4. 配置构建设置：
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
5. 点击"Deploy site"

### 自定义域名
1. 在Netlify控制台中，选择你的站点
2. 点击"Domain settings"
3. 点击"Add custom domain"
4. 按照提示完成域名配置
